### 📔 1 과목. 소프트웨어 설계

### **1 장. 요구사항 확인**

### 1️⃣ 소프트웨어 생명 주기 A

- **소프트웨어 개발 방법론**
    1. 폭포수 모형
    2. 프로토타입 모형
    3. 나선형 모형
    4. 애자일 모형

### 2️⃣ 스크럼(Scrum) 기법 C

- **스크럼팀**
    1. 제품 책임자
    2. 스크럼 마스터
    3. 개발팀
- **스크럼 개발 프로세스**
    - 스프린트 계획 회의 → 스프린트 → 일일 스크럼 회의 → 스프린트 검토 회의 → 스프린트 회고

### 3️⃣ XP(eXtreme Programming) 기법 B

- **XP의 5가지 핵심 가치**
    1. 빠른 개발
    2. 릴리즈 기간을 짧게 반복하여 요구사항 반영에 대한 가시성 up
    3. 릴리즈 테스트에 고객이 직접 참여
    4. 소규모 인원에 적합
    5. 애자일 개발 방법론 기반
- **XP 개발 프로세스**
    - 사용자 스토리 → 릴리즈 계획 수립 → 스파이크 → 이터레이션 → 승인검사 → 소규모 릴리즈
- **XP의 주요 실천 방법**
    1. Pair Programming
    2. Collective Ownership
    3. Test_Drive Development
    4. Whole Team
    5. Contiuous Integration
    6. Design Improvemnet
    7. Small Release

### 4️⃣ 현행 시스템 파악 C

- **현행 시스템 파악 절차**
    1. 1단계
        - 시스템 구성 파악
        - 시스템 기능 파악
        - 시스템 인터페이스 파악
    2. 2단계
        - 아키텍처 구성 파악
        - 스프트웨어 구성 파악
    3. 단계
        - 하드웨어 구성 파악
        - 네트워크 구성 파악

### 5️⃣ 개발 기술 환경 파악 C

- **운영체제(OS, Operation System)**
    - 시스템의 자원들을 관리 및 효율적인 사용을 위한 환경 제공을 위한 소프트웨어 제공
    - ex) Windows, UNIX, Linux, Mac OS, iOS, Android 등
    - 운영체제 관련 요구사항 식별 시 고려사항
        - 가용성
        - 성능
        - 기술 지원
        - 주변 기기
        
        - 구축 비용
- **데이터베이스 관리 시스템(DBMS)**
    - ex) Oracle, MySQL 등
    - DBMS 관련 요구사항 식별 시 고려사항
        - 가용성
        - 성능
        - 기술 지원
        - 상호 호환성
        - 구축 비용
